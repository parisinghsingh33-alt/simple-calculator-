# simple-calculator-
Simple Calculator
About the Project

This is a simple calculator project that performs basic mathematical operations such as addition, subtraction, multiplication, and division. It is designed to be easy to use and provides a simple way to perform everyday calculations.

I created this project to improve my programming skills and gain practical experience in building a working application.

Features
Addition, subtraction, multiplication, and division
Simple and user-friendly interface
Easy to use
Performs basic mathematical calculations
Technologies Used
HTML
CSS
JavaScript
How to Run
Clone this repository to your computer.
Open the project folder in Visual Studio Code.
Open the index.html file in your browser.
Start using the calculator.

You can also use the Live Server extension in Visual Studio Code to run the project.
